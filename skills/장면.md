# 장면 스크립트 작성

ADV 장면을 아래 텍스트 형식으로 쓴다. 형식이 헷갈리면 먼저 `search`로 기존 장면 문서(예: SCENES)를 찾아 1~2개만 구획 단위로 읽고 따라 쓴다.

## 형식
```
## 주연: 이름, 이름
## 본문
{bg=장소 bgm=곡} 지문 한 줄
이름 (속마음) {L smile sfx=효과}: 대사
지문만 있는 줄
[조연]
이름 {R tired}: 대사
## 조연 후보이름
이름: 대사
## 결과 1 [키]  // 메모
이름: 대사
```
- 위치 태그 L C R, 표정 base smile grin laugh serious angry sad surprise worried tired smug shy blank
- 옵션: bg= bgm= sfx= fx=(shake flash fade dark glitch) name=, `퇴장`, `퇴장=이름,이름`, `등장=이름@R/smile`
- 치환: {pc}=플레이어 캐릭터(레이첼), {sub}=조연으로 고른 인물

## 규칙 (반드시)
- 본문 15~25줄. `[조연]`은 정확히 1번.
- 조연 후보 4~6개, 각 2~5줄. 결과는 3~6줄.
- 본문 첫 줄에 bg= 와 bgm= 를 둔다. sfx는 장면 전체에서 2~4개.
- 대사는 따옴표 없이, 자연스러운 구어체 한국어. 속마음 (…)은 장면 전체에서 0~1줄.
- 숫자는 아라비아 숫자로 쓴다 (예: 3잔, 2시간). "한 번 더", "한 잔 하자" 같은 관용 표현은 예외.
- 인물의 말투·성격은 `docs/VOICES.md` 등 말투 문서의 해당 인물 구획을 `read_note`의 section 으로 읽어 확인한다 (파일 전체를 읽지 않는다).
- 원본 설정과 충돌하는 내용(금지 설정)을 만들지 않는다. 불확실하면 쓰기 전에 질문한다.

## 작업 순서
1. 요청에서 등장인물·장소·상황을 정리하고, 필요한 인물 문서/말투 구획만 읽는다.
2. 초안을 `write_note`로 `drafts/장면/<짧은이름>.md`에 저장한다.
3. 반환된 린트 결과의 error 를 고쳐 같은 경로에 `edit_note`로 반영한다.
4. 마지막에 한두 문장으로 요약하고, 사용자가 승인할 수 있도록 어떤 파일을 만들었는지 알려 준다. 본문 전체를 답변에 다시 붙이지 않는다.
