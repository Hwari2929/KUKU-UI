# 대사 다듬기 · 말투 점검

- 대상 인물의 말투 구획을 `read_note`의 section 으로 읽고(예: 말투 문서에서 인물 이름 구획), 말끝·호칭·금지 표현을 확인한 뒤 작업한다.
- 대사는 따옴표 없이 자연스러운 구어체 한국어로. 숫자는 아라비아 숫자.
- 점검 요청이면: 어긋난 대사를 `줄 → 제안` 으로 나열하고 이유를 한 줄씩 단다. 말투 문서의 어느 항목에 근거했는지 표기한다.
- 다듬기 요청이면: 원문과 수정본을 나란히 보여 주고, 파일 수정이 요청된 경우에만 `edit_note`로 반영한다.
